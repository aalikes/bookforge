    Setup Guide

    Readwise

    Get your access token from readwise.io/access_token and add it to your .env file.

    Notion

    Create a Notion integration, share a database with it, and add the API key and database ID to your .env file.

    GitHub

    Create a personal access token with repo scope. Set GITHUB_TOKEN and GITHUB_REPO in your .env.

    Obsidian

    Set OBSIDIAN_VAULT_PATH to your vault location, or use the Local REST API plugin.
