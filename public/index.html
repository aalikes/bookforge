    Setup Guide

    Goodreads

    CSV Import: Go to goodreads.com/review/import, click "Export Library", and upload the CSV.

    RSS Sync: Set GOODREADS_USER_ID in your .env. Find your ID in your Goodreads profile URL.

    Readwise

    Get your access token from readwise.io/access_token and add it to your .env file as READWISE_ACCESS_TOKEN.

    Notion

    Create a Notion integration, share a database with it, and add the API key and database ID to your .env file.

    GitHub

    Create a personal access token with repo scope. Set GITHUB_TOKEN and GITHUB_REPO in your .env.

    Obsidian

    Set OBSIDIAN_VAULT_PATH to your vault location, or use the Local REST API plugin.
